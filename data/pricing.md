# Pricing Information

## Subscription Plans

### Free Plan
- Price: $0/month
- Features: Basic search, up to 100 documents, 100 API calls/month
- Users: Personal use only
- Support: Community forums

### Professional Plan
- Price: $19/month
- Features: Advanced search, up to 10,000 documents, 10,000 API calls/month
- Users: Up to 5 users
- Support: Email support (24-hour response)

### Enterprise Plan
- Price: Custom pricing
- Features: Unlimited documents, unlimited API calls
- Users: Unlimited
- Support: Priority phone support, dedicated account manager

## Add-ons

### Extra Storage

- $99/month

### API Acceleration

## Billing Information

### Payment Methods
- Credit/Debit cards (Visa, MasterCard, Amex)
- PayPal
- Bank transfer for annual plans

### Billing Cycle
- Monthly: Charged on the same day each month
- Annual: 20% discount, one payment per year
- No setup fees or hidden charges

### Cancellation
- Cancel anytime with no penalties
- Refunds prorated for unused time
- Automatic downgrade to Free plan on cancellation
